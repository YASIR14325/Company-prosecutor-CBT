# UPSC Company Prosecutor CBT

A client-side computer-based test simulator for UPSC Company Prosecutor preparation.

## Included

- UPSC-style objective test interface
- 120 questions, 300 marks, 120 minutes
- +2.5 for a correct response and −1/3 of the question marks (−0.8333) for an incorrect response
- Question palette, mark-for-review, clear response, previous/next navigation, autosave in the browser
- Detailed result report with section-wise performance and answer explanations
- Broad coverage of Companies Act, corporate and insolvency law, criminal law and procedure, evidence, Constitution, economic offences, IT and allied laws

This is a practice simulator, not an official UPSC paper. Always verify the latest UPSC notification, applicable statutory amendments, and whether a particular statute has been replaced or amended before relying on a question.

Open `index.html` in a browser, or deploy the repository with GitHub Pages.
