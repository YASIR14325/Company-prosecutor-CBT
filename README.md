# UPSC Company Prosecutor CBT

A client-side computer-based test simulator for UPSC Company Prosecutor preparation.

## Open the CBT

### Run it directly on your computer

1. Click [`index.html`](./index.html) in this repository.
2. Click **Download raw file** or download the repository as a ZIP.
3. Keep `index.html`, `styles.css`, and `app.js` in the same folder.
4. Double-click `index.html` to open the CBT in your browser.

> Opening the file on GitHub displays the HTML source code. To use the simulator, download the files or open the deployed GitHub Pages link below.

### Deploy and access it online with GitHub Pages

1. Open the repository **Settings** tab.
2. Select **Pages** under **Code and automation**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and the `/ (root)` folder, then click **Save**.
5. After GitHub finishes deploying, open:

   **https://yasir14325.github.io/Company-prosecutor-CBT/**

The online CBT is served from [`index.html`](https://github.com/YASIR14325/Company-prosecutor-CBT/blob/main/index.html), with its styling in [`styles.css`](https://github.com/YASIR14325/Company-prosecutor-CBT/blob/main/styles.css) and question logic in [`app.js`](https://github.com/YASIR14325/Company-prosecutor-CBT/blob/main/app.js).

## Included

- UPSC-style objective test interface
- 120 questions, 300 marks, 120 minutes
- +2.5 for a correct response and −1/3 of the question marks (−0.8333) for an incorrect response
- Question palette, mark-for-review, clear response, previous/next navigation, autosave in the browser
- Detailed result report with section-wise performance and answer explanations
- Broad coverage of Companies Act, corporate and insolvency law, criminal law and procedure, evidence, Constitution, economic offences, IT and allied laws

This is a practice simulator, not an official UPSC paper. Always verify the latest UPSC notification, applicable statutory amendments, and whether a particular statute has been replaced or amended before relying on a question.
